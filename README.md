# YouTube Clone

A front-end clone of YouTube's homepage, built using **HTML and CSS**.

This project recreates the layout and design of YouTube's video browsing homepage, including the header, search bar, sidebar, video thumbnails, channel profile pictures and video information.

## Preview

The project includes:
- YouTube-style navigation header
- Search bar and action icons
- Sidebar with navigation options
- Video grid displaying 12 video previews
- Video thumbnails with duration labels
- Channel profile pictures and video details
- Clickable video thumbnails and titles that redirect to YouTube videos
- Clickable channel names and profile pictures that redirect to their respective channels

## Tech Stack

- **HTML5** – Structure and content of the webpage
- **CSS3** – Styling, layouts, positioning and responsiveness
